# Barcode Boss

> Mahalle marketinin patronu sensin.

Türkçe arayüzlü, mobil cihazlar için bir kasiyer / süpermarket
simülatör oyunu. Flutter + Flame ile açık kaynak geliştiriliyor.

## Hakkında

- **Tür:** Casual · Management · Time-pressure simulator
- **Platform:** Android (iOS post-launch)
- **Dil:** Türkçe
- **Lisans:** MIT
- **Durum:** Faz 5 — Closed Beta / Playtest

Oyunda mahalle marketinin patronusunuz: ürün siparişi verir, fiyat
ayarlar, kasada müşterilerin barkodlarını okutur, bozuk para verir,
karınızı maksimize etmeye çalışırsınız.
